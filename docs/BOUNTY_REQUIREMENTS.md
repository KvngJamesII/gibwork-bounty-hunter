## Goal

Create a **new non-web-app** use case for Gibwork using **SDK, CLI, or MCP** — practical developer workflows, automations, integrations, or tooling outside traditional web apps.

## Requirements

- Use Gibwork **SDK, CLI, or MCP** as a core part of the implementation
- Must be a **new** use case (not a minor variation of an existing demo)
- Must **not** be a web app, frontend dashboard, or browser-based product
- Solve a real developer / ops / automation / research / workflow problem
- Include setup instructions, dependencies, run/test steps
- Functional enough for basic reviewer validation
- Attend **≥ 2** Discord hackathon sessions

## What to submit

- Public GitHub repo + README
- Written summary: use case, value, which toolset (SDK/CLI/MCP)
- Setup/usage: install, env vars, commands, sample I/O
- Demo video / screen recording URL
- Screenshots (terminal, logs, agent interactions)
- Any exported deliverables if applicable
